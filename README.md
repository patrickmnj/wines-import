# Kenya Wine Imports Analysis — 2024

## Project Overview

As someone working in the hospitality industry, wine is a familiar part of restaurant and hotel operations. While learning data analytics, I decided to use wine imports as a practical dataset to explore where wine entering Kenya comes from and what the import data can tell us.

This project analyzes Kenya's wine import data for 2024 using Python and NumPy.

## Research Question

**Where does the wine imported into Kenya come from, and what can the 2024 import data tell us about Kenya's wine market?**

## Dataset

The dataset contains 2024 wine import information obtained from the World Integrated Trade Solution (WITS).

The main data file used in this project is:

WITS-By-HS6Product .csv

The analysis focuses on wine-related trade data and explores patterns in imports by trading partner and product.

## Analysis

The project uses Python and NumPy to:

* Load the CSV dataset
* Inspect the structure of the data
* Clean and prepare the data
* Explore wine import records
* Analyze import values and quantities
* Examine Kenya's trading partners
* Identify patterns in the 2024 wine imports
